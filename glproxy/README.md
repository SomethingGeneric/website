# Techjournal Submission Proxy

FastAPI service that accepts techjournal submissions from the static site, opens a GitLab issue, and now bootstraps a merge request that captures the submission details. Each merge request also updates `src/pages/techjournals/other-folks.astro` so the new entry shows up on the listing automatically. The GitLab access token stays on the server, so the public frontend never exposes it.

## Configuration

Set the following environment variables (they can be supplied via `docker run -e` or a `.env` file):

| Variable | Required | Default | Purpose |
| --- | --- | --- | --- |
| `GITLAB_API_TOKEN` | ✅ | — | Personal/project access token with “api” scope. |
| `GITLAB_PROJECT_PATH` | | `matt/website` | GitLab project namespace/path. |
| `GITLAB_API_BASE` | | `https://gitlab.goober.cloud/api/v4` | GitLab API base URL. |
| `ISSUE_LABELS` | | *(unset)* | Optional comma-separated labels for the created issue. |
| `ALLOWED_ORIGINS` | | *(wildcard)* | Comma-separated list of origins that may call the API. Enables restrictive CORS if set. |
| `ENABLE_MERGE_REQUESTS` | | `true` | Toggle automatic merge request creation. |
| `GITLAB_MR_TARGET_BRANCH` | | `main` | Target branch for the generated merge requests. |
| `GITLAB_MR_FILE_DIR` | | `incoming-techjournals` | Directory where the autogenerated submission stub lives. |
| `PORT` | | `8080` | Port to bind when running locally with `python app.py`. |

## Local development

```bash
cd glproxy
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export GITLAB_API_TOKEN=glpat-...           # required
python app.py
```

The service listens on `http://localhost:8080/techjournal` for `POST` requests with JSON:

```json
{
  "name": "Jane Doe",
  "link": "https://example.com/my-tech-journal",
  "role": "student",
  "gradYear": "2027"
}
```

## Docker Compose

1. Copy `.env.example` to `.env` and set the variables for your environment.
2. Start the proxy:

   ```bash
   cd glproxy
   docker compose up -d
   ```

The compose file builds the image, maps port 8080, and restarts the container automatically unless stopped manually. Update `PUBLIC_TECHJOURNAL_PROXY_BASE` in the Astro site to the proxy’s public URL (e.g. `https://proxy.mattcompton.dev`).

### Logs & Troubleshooting

- Tail logs with `docker compose logs -f techjournal-proxy`; each submission logs the issue, branch, and merge-request status.
- If merge creation fails the API responds with `mergeRequestError` (and optional `mergeRequestDetails`) that mirrors the GitLab response. These messages surface in the frontend success banner as well.
- Ensure the access token carries the **api** scope; merge automation needs to create branches, commits, and merge requests.
