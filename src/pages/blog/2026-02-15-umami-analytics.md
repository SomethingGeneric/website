# I decided I want analytics on this site
I know, I like privacy, so I figured I should write a blog post to explain my thinking.

## What software I picked
I am using the Umami analytics project, an open source (MIT license) and privacy-focused analytics platform

## But why
I want to be able to see how often certain pages are viewed, to thus focus my efforts better on where people are reading this website
(if they are at all, which I'm really not sure!)

## I don't like it!
That's ok!! The easiest way to out out, as mentioned on my policy page that can be read from the top nav-bar, you simply need to have an ad-blocker like U-block origin. If you didn't already notice my fake pop-up that suggests you should get an ad-blocker, chances are that you're already opted-out from Umami. 

You can check by reloading this page with your browser's developer tools open, and click on the network tab, then reload the page. If `nativeads.js` (this, by the way, is the script that generates the "you need an ad-blocker" pop up that you will have seen on my site if you don't already use one) and `script.js` from `umami.mattcompton.dev` are blocked, then you are opted-out.
